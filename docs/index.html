CORE2 DIRECT DRM SCANOUT · 2026-10-16

WPE 2.54.1：DRM/KMS実機表示経路の更新を確認

Ubuntu 24.04.5 / Intel Core 2 Duo T7250 / Intel 965GM (i915) / LVDS 1280×800

Core2本体にUbuntu 24.04互換WPEランタイムを導入し、headlessモードでHTML/JS動作確認。次にWPEPlatform DRMバックエンドでアニメーションHTMLをロードし、i915のCRTC・プライマリプレーンのスキャンアウトバッファが fb=81 → 82 ↔ 80 と切り替わることを51回観測しました。

WPE終了後は元の fb=81 に復帰。検証はroot不要、X11/Wayland不要です。

CORE2 SMARTPHONE REMOTE · 2026-10-16

QR接続・スマホ操作・物理キーボード

LAN上のスマートフォンでQRコードを読み取り、URL変更やタッチパッド風のマウス操作、クリック、スクロール、ASCIIキー入力を行う試験版を実装。X11/Waylandなしで、WPEPlatformのネイティブイベントを使います。

実機計測: 軽量HTMLを表示するWPE関連3プロセスで、75秒間の最大PSS 200.5 MiB・最大RSS合計 320.0 MiB・Swap 0 MiB。物理キーボードからJavaScriptへのイベント到達も確認。

どこまで実証できるか

  1. 静的テスト — JSの構文とUI動作
  2. ネイティブビルド — WPEPlatform 2.0 C APIへリンク
  3. WebKit実行テスト — headlessで読み込み→操作→描画状態の反映
  4. Core2実機 — HTML画像→fbdevの実メモリ書込・復元、GBM/GLES2、DRM masterを確認済み
  5. Core2のWPE直接表示 — i915 DRM/KMSの実スキャンアウト更新を51回検出し、元のコンソールへ復帰
  6. 目視・キーボード — 内蔵LCDへの実描画と物理キーボードからのJavaScript入力を確認
  7. スマホリモコン — QR認証、URL送信、WPEへのネイティブ入力注入を試作
  8. 未検証 — YouTube動画再生・日本語IME・2GBでのメモリ計測
